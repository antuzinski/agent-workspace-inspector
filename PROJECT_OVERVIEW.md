# Agent Workspace Inspector

**Обновлено:** 2026-10-10

## О проекте

Переносимый skill диагностики Codex и Claude Code с отдельными платформенными шаблонами harness; репозиторий также содержит исполняемую версию Unsnooze с checkpoint и необязательным Jev.

## Цели

- Проверять активную конфигурацию и выбирать обоснованное изменение с сохранением требований.
- Сдерживать лишний контекст и делегирование; отличать совместимость от измеренной эффективности.
- Предоставлять отдельно устанавливаемый Unsnooze для долговечных checkpoint и восстановления после лимитов без обязательного ключа Jev.

## Текущие результаты и статус

Claude-версия существовала; исправлены рекомендации по загрузке общих правил, приоритетам и использованию skills. Уточнены роли агентов и критерии завершения. Сверка от 2026-10-08 обновила рекомендации Codex/Claude по skills и hooks и сняла не обоснованный высокий effort worker. В каталог `unsnooze/` перенесён полный исполняемый пакет с тестами, лицензией исходного автора и локальными изменениями checkpoint/Jev. Skill и Unsnooze остаются раздельно устанавливаемыми компонентами. На 2026-10-10 сетевое чтение GitHub восстановлено, пользователь разрешил публикацию актуального harness. Добавлены снимок правил, навыков, ролей и экспериментального runtime, а также каталог выбора компонентов. Известные противоречия и неподтверждённая активация перечислены в harness/README.md. Активные настройки этой публикацией не мигрировались.

Далее при внедрении: проверить загрузку и поведение в целевых версиях Codex/Claude, затем сравнить результаты на одинаковых задачах. Для Unsnooze нужна проверка установки из репозитория на чистой машине и сравнение продолжения задач treatment/control. Локальный Claude CLI 2.1.30 не позволяет подтвердить новые механизмы проверки каталогов; эффективность не подтверждена.
