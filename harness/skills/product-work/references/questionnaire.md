# Questions for a knowledge holder

Identify the recipient, the decision to make, and which missing facts this person can supply. Reuse known context; ask the user only for a missing detail that materially changes the questionnaire. There is no mandatory interview before drafting it.

Give the recipient a short purpose. Put consequential questions first, one idea per question. Where it is not obvious, explain which choice depends on the answer. Prefer concrete examples, dates, constraints or records to general opinions; distinguish a fact from an estimate or preference. Avoid leading questions that assume the desired answer.

Include time expectations or a deadline only if known or explicitly proposed as such. Allow partial answers and “unknown”; identify a useful document or another contact when the recipient cannot answer.

Keep only questions whose answers could change the decision. This is a draft for a particular knowledge holder, not customer validation. Sending it requires explicit authorization; model-generated answers are never evidence from that person.
