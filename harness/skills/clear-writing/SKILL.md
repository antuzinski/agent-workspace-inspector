# Clear writing

Use this skill when the user asks to draft, revise, critique, or adapt a prose artifact. Preserve the author's meaning, voice, intended audience, and requested scope. Improve clarity without changing claims or certainty; flag ambiguity or unsupported causal claims instead of silently resolving them. Keep causal relationships and necessary qualifications intact.

Use familiar, concrete wording. Explain an abstract idea with one relevant example when it improves understanding. Avoid chopping connected ideas into jargon, unexplained labels, or fragments that make the logic harder to follow. Remove canned AI-sounding phrases and generic transitions; retain purposeful repetition when it aids the reader. Match the requested language and register.

Load only the language reference relevant to the task: [references/ru.md](references/ru.md) for Russian prose or [references/en.md](references/en.md) for English prose. References guide editorial choices; they do not override the author's voice or explicit instructions.
