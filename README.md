# Agent workspace configuration

Актуальные общие правила и навыки для Codex и Claude Code — без обязательного аудита, телеметрии и экспериментальных ограничителей. [English](README.en.md)

## Применение

Клонируйте весь репозиторий и попросите агента применить выбранные компоненты по `workspace-inspector/SKILL.md`. Для Codex объедините правила с действующим `AGENTS.md`, для Claude — с `CLAUDE.md`. Выбранные папки навыков перенесите в каталог навыков клиента. Сохраните исходные файлы и индивидуальные настройки. Установка одного inspector не устанавливает остальную поставку автоматически.

Личный config не распространяется. В текущей локальной настройке сняты ручной порог compaction и лимит результата инструмента, отключены старые context-guard/checkpoint-feedback hooks и JEV. Это не отменяет встроенные ограничения клиента. При обновлении удаляйте только настройки и регистрации обработчиков старой поставки. Unsnooze остаётся отдельным локальным средством восстановления и больше не поставляется здесь.

Встроенные навыки и плагины устанавливаются средствами клиента; их кэши сюда не копируются. Правила визуализации применяются при наличии нужного инструмента.

## Поддержка

После изменения общих локальных правил или навыков:

```sh
python scripts/sync-local.py
python scripts/sync-local.py --check
```

При необходимости задайте `--codex-home PATH`. Экспортируются шесть перечисленных навыков и правила без личных путей. Новые общие навыки добавляйте в список экспорта осознанно. Роли поддерживаются отдельно; скрипт не меняет выбор модели. Проверьте diff, ссылки и метаданные, затем создайте коммит и отправьте его в GitHub. Личные данные, аналитические отчёты и резервные копии не публикуются.

Обновление выполняется во время работы над настройками, а не фоновой службой. Для отката используйте оригиналы или историю Git. Совпадение файлов не доказывает активацию в новом клиенте.
